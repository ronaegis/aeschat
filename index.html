About AESchat

Features:
- Fast and easy way to securely chat
- No server: messages travel directly from browser to browser (WebRTC)
- End-to-end encryption done in the browser
- Uses bcrypt, SHA256 and AES-GCM
- Encryption key derived from the room name using bcrypt
- No message stored anywhere, history comes from the people in the room
- Source code at GitHub
- Easy to generate link addresses for other people to join

Good to know:
- People in the same room can see each other's IP address
- Public relays are only used to introduce browsers to each other
- Pick a random room name: anyone who guesses the name can join
